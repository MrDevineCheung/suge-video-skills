# suge-video-skills · 苏格拉没有底视频工坊

AI 代理用的出片 skill 合集，两种已验证风格：

- **漫画口播**（混知式彩色漫画，竖屏 1080×1920）：自录配音 → 逐字对齐 → canvas 渲染章节卡、盖章、漫画角色 → 钢琴配乐与音效混音。
- **像素卡点**（像素暖光故事，4:3 1440×1080，无口播）：社会痛点剧本公式 → 测配乐节拍网格 → Remotion 场景全部卡在乐句线 → 配乐接长/磁带停/回归 → 出片。

入口：`SKILL.md`。各风格细节：`styles/*/STYLE.md`。

注意：包内不含任何受版权保护的配乐，发布前请使用原创或已授权音乐。示例素材为 AI 生成，仅作模板参考。
