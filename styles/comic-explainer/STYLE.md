# 漫画口播（@苏格拉没有底）

混知式彩色漫画 + 用户自录口播，画面逐字跟着声音走。

样板作品：《数据已经这么多，为什么还要成立一家央企？》（7 章，约 10 分钟）。

## 一、成片规格

- 竖屏 1080×1920，30fps，H.264（crf 20）+ AAC 192k，faststart。
- 时长 = 配音实际时长 + 约 2.2s 片尾。
- 首帧 = 封面：成片前 0.4s 叠封面 PNG。
- 整片响度 -15 LUFS（两遍 loudnorm，linear=true），结尾 1.5s 淡出。

## 二、画面版式（从上到下）

1. **顶栏**（y≈66–256）：米白圆角框 + 黑描边，两行大标题约 60px，关键词橙色（如「数据」「央企」）。只写标题，不写系列名。
2. **章节小签**（y≈316）：橙底白字小 tag「二 · 新央企做什么」，章节卡收起后常驻。
3. **舞台区**（y≈270–1530）：角色、道具、卡片、箭头、盖章都在这里。
4. **字幕**（y≈1580）：50px 文楷棕色，按逗号句号自动断句，超过 16 字在顿号或逗号处折成两行。
5. **署名**（y≈1770）：灰字 `@苏格拉没有底` 38px。

- 背景：暖米色纸张底，带径向渐变和细噪点，可加缓慢旋转的橙色放射光（burst）。
- 字体：LXGW WenKai（霞鹜文楷），文字带深色描边。
- 色板：墨线 #141210；主强调橙 #EF7226；红用于叉和警示，绿用于对勾，蓝用于科技感；棕色正文。
- 描边：所有贴图卡片 6–7px 黑描边，加 10–12px 偏移的柔和投影。

## 三、角色与素材

- 风格：混知式 Q 版彩色漫画，大头身，表情鲜明，**干净、友好、精神、好看**。用户不接受丑的人物，配角也要顺眼（维修师傅曾被要求重画）。
- 生成：generate_image 出**纯绿幕底**单角色/道具，用 `key.py` 抠绿、去小连通域、裁边、限制 1100px，存为 `assets/c_<名>.png`。
- 贯穿角色：一个有表情的数据小方块（c_cube）当主角或吉祥物。
- 需要事实一致的形象（历史人物、机构）先按史实核对服饰。

## 四、「苏格拉没有底」水印（每条都要）

融进场景，不要角标水印：
- 木招牌：上行小字「苏格拉没有底」，下行大字「设备制造商 / 维修公司」等；
- 机器铭牌、大楼匾额、「苏格拉没有底交易所」门楣；
- 手机 App 顶栏、日历页脚「苏格拉没有底 日历」、订单小票「苏格拉没有底商城」、医院标牌；
- 结尾卡「这里是 苏格拉没有底」。

## 五、结构与节奏

- 开头：先口播一个问句（如「我们缺的，真的是数据吗？」），配方块从天而降堆成小山 + 问号弹出。
- 开头约 40s 交代新闻事实（日历翻页、新闻相框「据新华社报道」、大楼落成）。
- 分章节：每章开头一张**章节卡**（半透明米白遮罩 + 放射光 + 橙色圆形章号「二」+ 盖章式第一行黑字 + 橙色第二行），约 1.5s 后缩小飞到顶栏下变成小签。
- 章节内由 **beat** 组成：一个 beat 是一屏场景，时长跟着一段口播，进出用推屏（push）/上推（up）/缩放（zoom）转场 0.5s。
- 少切镜头，一屏多停一会儿；元素按关键词逐个弹出，不要一次堆满。
- 结尾：数据方块挥手 +「这里是 苏格拉没有底」+ 一句口号，停 2s。

## 六、动画语法（lib.js + render 里的 DSL）

- `el(kind, tin, tout, props)` 元素：`img`（贴图，可带 label 标签）、`tag`、`text`、`segs`（多色文字）、`stamp`（盖章，可加 shake）、`card`（图标卡片）、`sign`（水印招牌）、`check`、`cross`、`arrow`（手绘弯箭头）、`line`（虚线）、`bubble`（对话框）、`fn`（自定义绘制）。
- 出场：`popS` 回弹弹出 0.36–0.38s；退场淡出 0.3s；`mv` 让元素移动或缩放。
- 强调：盖章 + 轻微震屏；关键词橙色；划掉用红线 strike。
- 图标库：锁、复制、地图钉、书、钥匙、放大镜、芯片、闪电、风扇、沙漏、计算器、云、盾牌、文件夹、数据库、天际线、小票、银行卡、金币、天平等，都是 canvas 程序化绘制。

## 七、音画对齐（核心原则）

- **用用户自录原声，一字不剪**：不裁静音、不重排句子、不用 TTS 替代。只做 48k 重采样和整体线性增益。
- 对齐流程：
  1. `wh.py`：faster-whisper small（CPU int8）对整段配音做词级时间戳 → `whisper.json`（喂 numpy 数组，不要传文件路径）。
  2. `align2.py`：把文字稿 `script_paras.txt`（`#章节标题` 行标章节，`#开头` 行插开头问句）用 difflib 对到 whisper 逐字时间，阿拉伯数字转汉字再比；没对上的字线性插值 → `chars.json`（text, T 开始, E 结束, chapters）。
  3. 渲染脚本用 `K('关键词')` 按顺序游标查关键词出现时刻，所有元素的 tin 都挂在关键词上，所以**换一版语速的配音，只要重跑 1–2 步、改 AUDIO_DUR，再渲染即可自动对齐**。
- 画面比口播略早或同时出现；字幕在句子开始前 0.08s 出现，最长停到句尾后 1.2s。

## 八、声音设计（audio.py）

- 程序化钢琴配乐：C–Am–F–G，92 bpm，琶音 + 隔段旋律 + 简易混响；比人声低约 9dB，人声出现时再压 5dB（ducking，起 80ms 落 450ms）。
- 音效由渲染写出的 `events.json` 驱动：`pop` 弹出咔哒（约 -10dB）、`whoosh` 转场（约 -20dB）、`stamp` 盖章低频（约 -8dB）、`draw` 笔划沙沙（很轻，约 -35dB，60ms 淡入淡出）。
- 混音后两遍 loudnorm 到 -15 LUFS（单遍只能到 -17 左右）。

## 九、工作流

1. 收文案：核事实（新闻日期、机构数量等要搜原始报道），检查多音字与逻辑跳跃（如「第三关」前没讲第一、二关），提醒用户。
2. 先出分镜方案（贯穿全片的视觉线索，比如「能用→能流→能算→分配」旅程图），用户确认画风后再出样片（开头到第一章，约 80s）。
3. 正式配音到达：manus 分享链接用 `POST https://api.manus.im/session.v1.SessionPublicService/GetSharedSessionFile`，body `{"shareId":"<id>"}` 拿签名 fileUrl 下载 → ffmpeg 转 48k 单声道 `narration.wav`。
4. `python wh.py && python align2.py`，看 matched 比例（应在 97% 以上）和各章时间点。
5. `node render.js info / still <秒…>` 抽帧自查（拼成一排小图看）。
6. 分 3 段并行渲染：`node render.js video /tmp/p1.mp4 0 210 &` …，再 `ffmpeg -f concat -c copy` 拼接。
7. `python audio.py` → 两遍 loudnorm → `mux.sh` 合成（叠封面 0.4s、AAC 192k、faststart）。
8. 先写 /tmp 再拷进工作区（网络盘上 faststart 会 IO 报错）。只改音频不重渲画面；只改画面不动音频。
9. 抽 6 帧自查：首帧是封面、章节卡、水印、结尾卡、字幕对得上口播。

## 十、包内文件

- `templates/lib.js`：画布工具（贴图、文字描边、tag、气泡、盖章、放射光、手绘线与箭头、缓动、马克笔）。
- `templates/render_example.js`：《国家数据集团》完整渲染脚本，含开场、章节卡、beat DSL、图标库、封面模式；新主题复制后改标题、关键词锚点和 beat 内容。
- `templates/audio.py`：配乐 + 音效 + ducking 混音。
- `templates/wh.py`、`templates/align2.py`：词级转写与逐字对齐。
- `templates/key.py`：绿幕抠图。
- `templates/mux.sh`：响度归一与封面首帧合成。
- `examples/`：封面和抽帧示例，示例角色素材。
- 依赖：node 22 + @napi-rs/canvas，ffmpeg 7，python3 + numpy scipy pillow faster-whisper；字体 LXGW WenKai 放 `fonts/wk.ttf`（GitHub lxgw/LxgwWenKai 下载）。
