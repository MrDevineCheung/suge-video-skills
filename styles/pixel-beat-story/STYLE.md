# 像素卡点（pixel-beat-story）

一句话风格：**一间像素小屋、一盏会说话的小东西、一个说不出口的孩子/老人；没有旁白配音，只有打字对白、数字和音乐；每一刀都切在乐句上，最痛的地方音乐停下。**

参考成片：苏格拉没有底 ep53《他不是不说》、ep54《他不是来自星星》（4:07）。完整代码样例 `template/Ep54-example.tsx`，剧本样例 `template/ep54-script-example.md`，配乐整形样例 `template/ep54-music-ops.json`。

---

## 0. 先定的五件事（开工前问用户/自己定）

| 项 | 默认 |
|---|---|
| 画幅 | 4:3 横屏 1440×1080，30fps（竖屏就改 W/H 和房间裁切） |
| 时长 | 3–4.5 分钟；先做第一幕 60–70 秒样片给用户确认，再做全片 |
| 社会痛点 | 一个真实存在、观众身边就有的处境（孤独症、阿尔茨海默、留守、独居老人…），**不是**泛 AI/科技或纯知识 |
| 陪伴物 | 一个会说话的小物件（台灯、星星玩偶…）= 故事里的"翻译者"，**不是救世主** |
| 配乐 | 必须有授权才能发布；没有时可用参考音频占位，但交付时每次都提醒替换 |

## 1. 剧本公式（references/story.md 有完整模板）

四段，对应音乐的四个能量区：
1. **数字钩子（0–20s，前奏）**：一个反差数字。"他对星星说了 1368 句话，对妈妈 0 句。"
2. **误会与压力（强进后，第一幕）**：家人问→孩子沉默；外界（老师群、邻居、长辈电话）一层层加压；妈妈想"关掉"那个小物件。以一句悬念收（"她打开了对话记录"）。
3. **反转与学习（第二幕，全奏段）**：记录里全是妈妈（"找到 412 条"）；"他不是不说"；家长学方法（笔记本、转述、小道具伏笔），**有一次失败**。
4. **失去与回扣（第三幕，音乐安静段）**：小物件失效（停电/没电）→ 音乐停 → 家长用学会的方式陪伴 → 孩子第一次对家长开口，回扣片头数字/道具 → 音乐在那一句的拍上回来。
5. **结尾卡**：把一个常见标签/说法翻过来讲（"来自星星的孩子——其实就在这间屋子里"），一条有出处的数据 + "故事为虚构"。

硬约束：不说 AI 治愈任何病；不把孩子写成怪物或天使；不用真实儿童隐私；数据必须 web_fetch 出处原文核对。

## 2. 生产流程

工程：Remotion（weilanx-claude-videos 工程，组件放 `src/episodes/<期>/`，Root.tsx 注册 Composition + 封面 Still）。沙箱适配见 custom skill `weilanx-videos`（NODE_OPTIONS、--concurrency、不用 npx）。沙箱重置后先 `pip install numpy pillow scipy`。

1. **剧本** → `work/<期>-脚本.md`，等用户点头。
2. **测拍**：`python3 scripts/beats.py music.wav --click /tmp/ck.wav`。得到一拍 B、乐句线 `PH(m)=T0+8B·m`、每乐句响度表（↑=强进，≤-20dB=安静段，末尾=尾声）。听 click 校正，不准就 `--t0/--beat` 手动覆盖。自动结果可能差半拍，以耳朵为准。
3. **卡点稿**：把剧本每一场排到乐句上（见 §3），写进代码注释/`work/<期>-卡点稿.md`。总长不够就先规划配乐接长（§4）。
4. **素材**：generate_image 生成房间（16:9 或方图，像素风、暖光、带窗）、角色精灵（纯色背景，坐/站/蜷缩/背影多姿态，同一角色同一提示词骨架）、陪伴物。`python3 scripts/cutout.py raw.png out.png` 抠图裁边。放 `public/<期>/`。
5. **写场景**：复制 `template/Ep54-example.tsx`，保留"工具区"（节拍网格、Room/Sprite/Hud/Dialogue/Narr/Cut/Black/Rec/BigPhone/Ceiling/Rain/Clouds/Flash），替换场景函数。每个场景 = `<Cut a={PH(m)} b={PH(m+k)}>`。
6. **抽帧 QA**：`bash scripts/contact.sh <工程> <compId> "16 50 125 …"` → read_file 看联系表（§6 清单）。
7. **配乐整形**：`scripts/music_tools.py`（§4），环境声 `scripts/sfx.sh`。
8. **渲染**：`bash scripts/render.sh <工程> <compId> <总帧数>`（两段并行、静音，246 秒约 10–15 分钟）。
9. **封面**：Still 渲成 jpg；**封面压在第 0 帧**（每个视频都要）。
10. **混音出片**：`bash scripts/mux.sh /tmp/<id>_v.mp4 music.wav cover.jpg work/<片名>_4比3.mp4 <秒> [/tmp/rain.wav /tmp/thunder.wav]`。
11. 交付：display_file 发 mp4；说清时长、卡点亮点、配乐是否占位。局部修改只重渲受影响帧段再 ffmpeg 覆盖。

## 3. 卡点规则

- **硬切只在乐句线**（`PH(m)`），场景时长 = 整数个乐句（4.256s 的倍数）。段落内的情绪切换可以落在半乐句 `bt(m,4)`。
- **出现落拍**：对白、记录卡、星星、计数，`at = bt(m,k)`；成组的东西一拍一个（7 颗星 = 7 拍）。
- **数字落重拍**：大数字（412、1368）在乐句首拍计数完成，配 1–2 帧暖白闪。
- **强进 = 外界压力进场**（第一个 drop 切到家长群之类的嘈杂画面）。
- **安静段 = 失去**：停电/失去放在曲子的安静段，但**音乐不要自己先掉**——用 `hold` 撑到断点那一拍，再 `tapestop` + 雷声/闪白（§4）。
- **关键台词让音乐回来**：孩子第一次开口那句放在安静段结束的乐句首拍，音乐在这一拍"打开"（提问时先压到 55%）。
- 打字速度 cps：普通 13；孩子犹豫 4–9；陪伴物没电时 5。慢打字本身就是表演。
- 场景之间默认硬切 + 2 帧闪白；情绪场景用 0.35–0.5s 淡出到黑再切。

## 4. 配乐整形（scripts/music_tools.py）

- **接长**：`pick` 找和插入点前后和声最接近、能量相当的整乐句段；`insert` 等功率交叉淡化 1 拍、中心落在乐句线 → 网格不变、听不出接缝。插整乐句，插在安静段之前（让安静段对上第三幕）。
- **断点**：`hold`（把断点前的空档换成上一乐句内容，乐队撑住）→ `tapestop`（0.9s 速度 1→0 + 衰减，和雷声、画面断电同一帧）→ `silence`（只剩雨声）。
- **回来**：`fadein`（家长靠近时 3s 慢入）→ `gain` 在提问处压低、在关键台词那一拍 1.6s 放开。
- **结尾**：mux.sh 自动最后 1s 淡出；片尾黑场 0.8s。
- 避坑：ffmpeg `acrossfade` 对同一输入 split 出的多路会截断，一律用 numpy；处理是"就地改文件"，别对已处理的文件再跑一次（保留原始 wav）。
- 环境声用程序生成（sfx.sh 雨/雷），避免版权问题；雨声 0.22、雷声低通 180Hz。

## 5. 版式规格（references/layout.md 有数值表）

- **对白**：左上起（left 80, top 110），半透明玻璃底框 `rgba(8,9,14,0.66)` + 左侧 5px 角色色条，名字 21px，正文 ≥38px（默认 40）粗体，行高 1.42；只显示最近 3 句，旧句渐隐不占位。
- **旁白/字幕卡**：衬线 ≥44px（默认 48），居中，柔和暗色椭圆衬底，关键词金色 `<G>`。
- **HUD**：顶部左 "第 N 天 · 时间 · 状态" 24px，右侧计数器（"对妈妈说的话 0"），数字 30px；它是贯穿全片的进度线，最后一幕才变。
- **手机/记录卡**：720×980 手机，卡片日期 17px、正文 26px；搜索框里"找到 N 条"N 用金色大号。
- **结尾卡**：标题 100px 金色，演员表 28px；底部渐变压暗，数据 30px 粗体（数字金色）、出处 22px、虚构声明 24px、账号名 30px 金色衬线。**不加角标水印**，账号名只放片尾/画面内道具。
- 配色：孩子暖橙 `#ffb35c`、家长米白 `#f4efe6`、陪伴物冷蓝 `#8fc8ff`、强调金 `#f3c77a`、外人暗红；夜景房间 dark 0.5–0.75，陪伴物的光是唯一暖光源，失去时它熄灭。
- 字体：Noto Sans SC（对白/UI）+ Noto Serif SC（旁白/标题）。

## 6. QA 清单（每次渲染前抽帧看）

- 每个场景至少一帧；文字不出画、不压脸、不压窗外关键星星；对白 3 句时底部不越界。
- 计数器/HUD 时间线前后一致（天数递增、计数只在关键处 +1）。
- 安静段画面和音乐对齐：断电闪白帧 = tapestop 起点 = 雷声。
- 关键台词帧 = 音乐放开帧（比对 PH 值）。
- 封面在第 0 帧；最后 0.8s 黑场 + 音乐淡出；响度 -15 LUFS（mux.sh 已做两遍 loudnorm）。

## 7. 交付话术

一条消息：片长、两三个卡点亮点、配乐是否为占位（占位必须提醒替换授权曲）、问哪里想调。全片前先交第一幕样片。
